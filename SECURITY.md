## Reporting a Vulnerability

If you discover a potential security vulnerability within any of my projects (including core platforms, WordPress plugins, or API integrations), please report it responsibly:

- **Private Inquiries & Reporting**: Please reach out via Twitter/X direct message: [Twitter/X (@mrghozzi)](https://twitter.com/mrghozzi) or [Facebook](https://facebook.com/mr.ghozzi).
- **Response Window**: Initial response and acknowledgement are typically provided within 24 to 48 hours.
- **Responsible Disclosure**: Please refrain from publicly disclosing or exploiting the vulnerability until an official patch or resolution has been released.

Thank you for contributing to keeping the open-source community secure!
